# Description

This repository implements some generative adversarial networks (GAN) algorithms used for generating synthetic images. The codes were adapted from https://github.com/eriklindernoren/PyTorch-GAN with some modifications.

The implemented models include GAN, Conditional (CGAN), Deep Convolutional GAN (DCGAN), Cylce GAN, and Wasserstein GAN GP (WGANGP).
